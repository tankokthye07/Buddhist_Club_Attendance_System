There are many files here which are individual yet connected pages.

To start, activate Xampp Control Panel, turn on myPHP admin, apache and relevant fields (PS: The admin column for the 1st, 2nd and 5th button).

Then click on start for the MyPHP admin row, you will be sent to the database associated with this current system, where records and attributes with relevant relationships among entities are stored here.

There are 5 main relationships & tables that can be found and managed in there.

Manage student IDs with Activity IDs, monitor their attendance with online attendance system that can be deployed on campus with wifi connection.

Start with Index.html for complete experience.

You can import KodKelas.csv to test the import feature for adding more class codes. Alter the contents for wider variety of testings.
